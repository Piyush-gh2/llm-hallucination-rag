Artificial Intelligence

Artificial Intelligence is a field of computer science focused on creating systems that can perform tasks that normally require human intelligence.

Machine Learning

Machine Learning is a subset of Artificial Intelligence. It allows computers to learn patterns from data and make predictions without being explicitly programmed for every task.

Deep Learning

Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers to learn complex patterns from large amounts of data.

Natural Language Processing

Natural Language Processing, or NLP, is a field of Artificial Intelligence that focuses on enabling computers to understand, process, and generate human language.

Large Language Models

Large Language Models are machine learning models trained on large collections of text. They can generate, summarize, classify, and transform natural language.

Retrieval Augmented Generation

Retrieval-Augmented Generation, commonly called RAG, combines information retrieval with language generation. A RAG system retrieves relevant information from a knowledge source and provides that information to a language model before generating an answer.

RAG can help reduce hallucinations because the language model can use retrieved information as context when generating its response.

Hallucination

An AI hallucination occurs when an AI model generates information that is unsupported, inaccurate, or inconsistent with the available evidence.

Vector Database

A vector database stores numerical representations of information called embeddings. These representations can be used to find semantically similar information.

FAISS

FAISS is a library developed for efficient similarity search and clustering of dense vectors.

Embeddings

Embeddings are numerical representations of text, images, or other data. Similar pieces of information generally have embeddings that are close together in vector space.

Transformers

Transformers are a neural network architecture widely used for natural language processing. They use attention mechanisms to process relationships between elements in a sequence.
